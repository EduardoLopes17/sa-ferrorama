## Mapeação no Código dos Métodos não compreendidos:

**filter_input** = Obtém uma variável externa específica pelo nome e, opcionalmente, aplica um filtro a ela.

**in_array** = Verifica se um valor existe em um array

**mb_strlen** = Obter o comprimento da string

**filter_input** = Obtém uma variável externa específica pelo nome e, opcionalmente, filtra-a

**$_SERVER** = $_SERVER é um array que contém informações como cabeçalhos, caminhos e locais de scripts. As entradas nesse array são criadas pelo servidor web. Não há garantia de que todo servidor web fornecerá todas elas; os servidores podem omitir algumas ou fornecer outras que não estão listadas aqui. Dito isso, um grande número dessas variáveis ​​está previsto na especificação CGI/1.1, portanto, é razoável esperar que elas estejam presentes.

**error_log** = Envie uma mensagem de erro para as rotinas de tratamento de erros definidas.

**num_rows** =  Retorna a quantidade de linhas da consulta.

**json_encode** = Retorna a representação JSON de um valor.

** http_response_code** = Obter ou definir o código de resposta HTTP

**array_slice** = Extraia uma fatia do array

**preg_replace** = Realizar uma busca e substituição com expressão regular

**preg_match** = Realizar uma correspondência por expressão regular

**strtoupper** = Converter uma string para maiúsculas

**password_hash** = Cria um hash de senha

**session_regenerate_id** = Atualize o ID da sessão atual por um recém-gerado

**ini_get** = Obtém o valor de uma opção de configuração

**session_destroy** = Destrói todos os dados registrados em uma sessão

**date_default_timezone_set** = Define o fuso horário padrão utilizado por todas as funções de data/hora em um script

**COALESCE** = Unir, fundir ou aglutinar partes separadas em um único todo ou sistema

**strtotime** = Converta praticamente qualquer descrição textual de data e hora em inglês para um timestamp Unix.

**bind_param** = Liga variáveis a marcadores de parâmetros em uma consulta SQL preparada (prepared statement)
