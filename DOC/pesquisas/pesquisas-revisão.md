## Revisão Geral ## 

 
# APIs 

1. API: É uma ponte que permite dois sistemas trocarem informações.

2. Comunicação: Um sistema faz um pedido e o outro devolve uma resposta.

3. API REST: Permite buscar, cadastrar, alterar e excluir dados.

4. Métodos HTTP:
- GET: buscar.
- POST: cadastrar.
- PUT: alterar.
- PATCH: alterar parte.
- DELETE: excluir.

5. HTTP: É a comunicação entre cliente e servidor, através de pedidos e respostas.

6. Endpoint: É o endereço usado para acessar alguma função ou dado da API.

7. JSON: Formato usado para organizar e enviar dados entre sistemas.

8. PHP com API: O PHP pode usar cURL para acessar uma API e json_decode() para interpretar os dados.

9. Disponibilização de dados: A API libera informações por meio de endpoints.

10. Segurança: Autenticação identifica quem acessa, autorização define permissões e HTTPS protege a comunicação.

11. Utilização: APIs são usadas em pagamentos, lojas, entregas, estoques e sistemas empresariais.


# CRUD em PHP

1. CRUD: É um conjunto de quatro operações usadas para mexer nos dados de um sistema.

2. Funcionamento: O PHP recebe os dados do usuário e envia comandos para o banco de dados.

3. Create: Serve para cadastrar e salvar novas informações.

4. Read: Serve para consultar e mostrar informações que já estão salvas.

5. Update: Serve para alterar informações já cadastradas.

6. Delete: Serve para excluir informações do banco de dados.

7. SQL: É a linguagem usada para realizar essas operações no banco de dados.

8. PHP e banco de dados: O PHP faz a ligação entre o site e o banco, enviando e recebendo informações.

9. Conexão: Pode ser feita usando PDO ou MySQLi, que permitem ao PHP trabalhar com o banco de dados.

10. Utilização: O CRUD é usado em cadastros de alunos, produtos, clientes, estoques e vários outros sistemas.


# PDO no PHP

1. PDO: É um recurso do PHP que permite conectar o sistema a um banco de dados.

2. Utilização: Serve para cadastrar, consultar, alterar e excluir informações no banco.

3. Conexão: É feita informando dados como servidor, nome do banco, usuário e senha.

4. Compatibilidade: O PDO pode trabalhar com diferentes bancos de dados, como MySQL, PostgreSQL e SQLite.

5. Prepared Statements: São consultas preparadas que ajudam a deixar os comandos SQL mais seguros.

6. Segurança: Ajuda a evitar SQL Injection quando os parâmetros são utilizados corretamente.

7. Tratamento de erros: Permite identificar e tratar problemas que podem acontecer durante a conexão ou consultas.

8. Transações: Permitem agrupar operações no banco e confirmar ou desfazer alterações.

9. PDO x MySQLi: O PDO funciona com diferentes bancos de dados, enquanto o MySQLi é voltado para o MySQL.

10. Vantagens: Ajuda na organização do código, segurança e conexão com diferentes bancos de dados.

11. Utilização no Ferroramas: No projeto, usamos MySQLi, mas o PDO é outra forma de conectar o PHP ao banco de dados.


# Metodologia Ágil SCRUM

1. SCRUM: É uma metodologia ágil usada para organizar o desenvolvimento de projetos, dividindo o trabalho em etapas menores chamadas Sprints.

2. Objetivo: Organizar o trabalho, melhorar a comunicação, entregar resultados mais rápido e facilitar mudanças durante o projeto.

3. Product Owner: É quem define o que deve ser feito no projeto e quais tarefas são mais importantes, organizando o Product Backlog.

4. Scrum Master: Ajuda a equipe a seguir o SCRUM, organiza o processo e procura resolver obstáculos que atrapalham o trabalho.

5. Development Team: É a equipe responsável por desenvolver o sistema, trabalhando em conjunto para entregar as funcionalidades.

6. Sprint: É um período de trabalho com duração definida, geralmente de uma a quatro semanas, em que a equipe desenvolve uma parte do projeto.

7. Sprint Planning: É a reunião no começo da Sprint, onde a equipe decide o que será feito durante aquele período.

8. Daily Scrum: É uma reunião rápida diária para falar sobre o que foi feito, o que será feito e se existe algum problema.

9. Sprint Review: É a reunião em que a equipe apresenta o que conseguiu desenvolver durante a Sprint e recebe opiniões sobre o resultado.

10. Sprint Retrospective: É a reunião em que a equipe analisa o que deu certo, o que deu errado e o que pode melhorar no próximo ciclo.

11. Benefícios: Ajuda a organizar tarefas, melhorar a comunicação, diminuir problemas, acompanhar o projeto e se adaptar às mudanças.

12. Utilização: O SCRUM é bastante usado no desenvolvimento de sistemas e softwares, principalmente em equipes que precisam trabalhar de forma organizada e com entregas frequentes.


# XAMPP

1. XAMPP: pacote que permite transformar o computador em um servidor local para desenvolver e testar sites.

2. Localhost: endereço usado para acessar o servidor local pelo próprio computador.

3. Apache: servidor web responsável por receber pedidos do navegador e mostrar os arquivos do site.

4. PHP: linguagem de programação que faz o sistema funcionar, processa informações e conecta ao banco de dados.

5. MySQL/MariaDB: banco de dados onde ficam armazenadas as informações do sistema.

6. phpMyAdmin: ferramenta visual usada para criar e gerenciar bancos de dados e tabelas.

7. Como iniciar: abrir o painel do XAMPP e clicar em Start no Apache e no MySQL.

8. htdocs: pasta onde ficam guardados os arquivos dos projetos para rodar no servidor local.

9. Acesso ao projeto: os projetos podem ser acessados pelo navegador usando localhost e o nome da pasta.

10. Banco de dados: pode ser criado e gerenciado pelo phpMyAdmin, acessado pelo navegador.

11. Vantagens: permite testar sistemas com segurança, rapidez e sem precisar pagar hospedagem.

12. Utilização: muito usado para desenvolver e testar sites e sistemas em PHP antes de colocá-los na internet.
