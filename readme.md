SA-Ferrorama
 Equipe: Eduardo Lopes, Guilherme Floriano, Hugo Gramme, Luis Gustavo.
 
 Proposta do sistema:
A proposta do nosso sistema é criar um site que permita visualizar informações sobre trens coletadas a partir de sensores.

 Objetivos:
Permitir a visualização das informações dos trens.
Coletar informações sobre os sensores IOTs.
Criar uma plataforma para visualização dos relatórios coletados dos sensores.

 Tecnologias Utilizadas:
HTML
CSS
Javascript
PHP
MySql

 Metodologias de Desenvolvimento:
Kanban
Scrum
